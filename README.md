# Backend Track - Campus Notifications

Repository for the Campus Notifications Microservice assessment.

## Contents
- `logging_middleware` - The reusable logger package
- `notification_app_be` - Implementation for Stage 6 (Priority Inbox)
- `notification_system_design.md` - System design and database architecture answers

## Running Stage 6

Make sure you have a `.env` file placed in the root directory with the API credentials before running.

```sh
cd notification_app_be
npm run start
```
